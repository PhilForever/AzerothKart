# Azeroth Kart — developer installation

This folder is the WoW addon source for a local three-lap prototype with Test Oval and a selectable Mirage Raceway blockout. Install it as `Interface/AddOns/AzerothKart` for the verified Forever client. The `_Camelot.toc` is the documented flavor; the base `.toc` is the fallback. Confirm runtime TOC selection after client changes.

After updating, run `/reload`, then `/akart`. While stopped, click **Track: Test Oval** to select **Track: Mirage Raceway**. Click the same button to return to Test Oval. A successful map change clears the previous run and timing sample; a failed background load leaves the existing track and result intact. Test Oval is the default after reload; selection is not saved. Mirage uses one original geometry-aligned `Assets/Tracks/SaltFlats/Background.tga`, with the existing placeholder kart. The square map is centered at 480×480 inside the 800×480 canvas; kart, gate and wall dimensions scale uniformly. Painterly scenery and Warcraft-like vehicle sprites are still planned. The source checkout includes the layout guide and art brief under `docs/art/`.

Deliberately click **Start Test Drive** outside combat. The kart stays at spawn through 3–2–1; held controls begin driving after GO. W/Up accelerates, S/Down brakes/reverses, and A/D or Left/Right steers. Hold Space while turning on the road at speed 90+ to charge a drift; release Space while keeping the turn to boost. Grass (rough salt on Mirage) slows the kart and cancels drift/boost; perimeter walls scrub speed while allowing sliding.

Drive counterclockwise through North, West, South and Start. Race/lap time starts at GO and excludes the countdown and dropped/stopped time; physics/probe ticks include the 180 countdown ticks. A hitch can lengthen countdown wall time. The third ordered lap ends the run at its exact simulation tick, releases controls and shows total/last-lap times plus the best completed lap of this run. The lap HUD shows `Best: --` until a completed lap; a strictly faster completed time replaces it, while ties keep the earliest lap. Incomplete laps never become the best. Stop/Escape, Close, another key, chat focus, any mouse click, hiding or focus loss releases capture. Combat closes the window and retains an interrupted partial result. Reopening and rejected Starts retain the frozen summary and best lap; deliberately click **Restart** or Start for a fresh countdown and run. Stopping during countdown retains zero race elapsed time. Capture never resumes automatically.

`/akart probe` or **Print Probe** reports timing, capabilities and explicit UI counts only on request. The best lap resets on a successful fresh Start/Restart or map change and is not a saved personal record. There is no networking, saved race progress or persistence of results. M0/M1/M3 acceptance remains open; Mirage custom-texture loading/orientation and current client handling/countdown/finish/restart appearance are **NOT RUN**. Those links resolve in the source checkout.
